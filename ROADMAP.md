# Roadmap

Open work only. Delete an entry in the PR that finishes it; git history is the record.

## Ideas

- **Root bundle back to 100 KB** (2026-11-05): everything from `nish-ui` is 140.89 KB gzip (target 100; Calendar, DatePicker, MultiSelect and Carousel added 8.4 KB; RangeCalendar, DateRangePicker and TimeField added 4.60 KB in 2.2.0, and the shared CalendarBase plus their 9 strings added 0.5 KB to Calendar and DatePicker). Not reachable in 2.x: SystemCanvas, Inbox and the service-token components have to leave the root entry (SystemCanvas already has `nish-ui/system-canvas`), a 3.0 change (see "Other 2.0 leftovers"). AppShell is 35.0 KB (target 34); next levers: per-component string defaults (every string in `DEFAULT_STRINGS` ships with every component that reads strings; the 31 picker, time and carousel strings cost each of them about 0.34 KB), and Toaster cards loaded on demand, with a fallback for a chunk that cannot load.
- **Other 2.0 leftovers** (2026-11-03): a CommonJS build and React 18 support, only if an outside user asks. In 3.0, remove the `Switch` `onChange(checked, event)` signature in favor of `onCheckedChange`, and take the fleet-only names (Inbox, ServiceTokensSection, useServiceTokens, SystemCanvas and their helpers) off the root entry; they stay on `nish-ui/inbox`, `nish-ui/service-tokens` and `nish-ui/system-canvas`.
- **Docs demos lose `nish-pad-bottom-inset` to a padding utility** (2026-11-07, ui-pad-bottom): the class is in the base layer, so `py-4` beats it in `site/components/bottom-nav.tsx` and `sticky-action-bar.tsx`, and the inline `padding` in `static-parity.tsx` does too. Use `pt-4` plus `pb-[max(calc(var(--nish-bottom-inset,0px)+1rem),calc(1rem+env(safe-area-inset-bottom)))]` there, as PageContainer does since 2.1.3.
- **Range and time picker leftovers** (2026-11-07, range-picker review): (1) the docs story frame (`site/pages/frame.tsx`, `p-6`) leaves a 278px DateRangePicker at 360px, so its placeholder "MM/DD/YYYY – MM/DD/YYYY" is clipped by one character inside the input (in an app with 16px gutters it fits); try `p-3 sm:p-6` and check the Fold visual diff. (2) Calendar's and RangeCalendar's today ring is a box-shadow, so it disappears in forced colors; add a forced-colors outline for today. (3) TimeField looks up its Field label id only when `id` changes, so a Field label that mounts later is not picked up.
