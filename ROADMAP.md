# Roadmap

Open work only. Delete an entry in the PR that finishes it; git history is the record.

## Ideas

- **Components left out of 2.0** (2026-11-03): DatePicker and Calendar, MultiSelect, virtualized lists and tables, ContextMenu, HoverCard, TreeView, Carousel. Each follows the component contract in docs/DEVELOPING.md and gets a docs page, unit tests and a size budget.
- **Size budgets back to the 2.0 targets** (2026-11-03): AppShell is 37 KB gzip (target 34), SystemCanvas 27.1 KB (target 27) and everything from the root 117 KB (target 100); AppShell and SystemCanvas pull in all of overlay.js. Split overlay.js (Modal, Drawer, Popover, Tooltip) into separate modules or lazy-load the Drawer and MoreSheet from AppShell, then lower the budgets in tools/size-budgets.json.
- **Other 2.0 leftovers** (2026-11-03): docs-site bundle splitting and fewer iframes on the /themes views; SystemCanvas routing performance at 500 nodes; a CommonJS build and React 18 support only if an outside user asks. Raise the mutation score of `src/theme.ts` (39% in 2.0; 478 mutants run in no Vitest test because the theme functions are only exercised by the build-time self-tests in scripts/build.mjs). Mark the fleet-only APIs (inbox, service tokens, SystemCanvas) as internal in the docs or move them to a subpath, so outside users know what is covered by semver. In 3.0, remove the `Switch` `onChange(checked, event)` signature in favor of `onCheckedChange`.
- **AppShell gaps that keep four apps on local shells** (2026-11-02, found adopting 1.7.0): trading wants the lg+ layout without a header (brand, wordmark subtitle and tools in the sidebar), short rail labels per item and nav links that remember each section's last URL; job-apps wants pill tabs with a badge, an explicit list of bottom-bar items instead of the first N, a full-height page and a header `innerClassName`; status wants header tabs at every width instead of the bottom bar and rail (two items); trackers wants placeholder tabs while auth is unknown, a footer slot and a header width. Each app then deletes its own shell. Repos: ui, then trading, job-apps, status, trackers.
- **Wave 3 element follow-ups** (2026-11-02): add parity cases for the Stage E classes and states not covered yet; add touch/focus regression specs for the coarse-pointer chip width, the command input focus ring and the stacked split panes.
