# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest 3.x | Yes |
| 2.x | Security fixes only, for 3 months after 3.0.0 is released (2026-11-07) |
| 1.x | No |

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Report it privately with GitHub's
[private vulnerability reporting](https://github.com/nishant/ui/security/advisories/new)
(the Security tab of this repository, then "Report a vulnerability").

Include the affected version, what an attacker can do, and the smallest steps or code that show
it. A proof of concept helps.

## What to expect

- An acknowledgement within 3 days.
- An assessment and a plan within 14 days.
- A fix released as a patch of the latest supported version as soon as it is ready, with credit
  in the advisory and CHANGELOG if you want it.

Reports about the docs site (https://design.nish.software) are welcome through the same channel.
